# Accurate 5 Standard Desktop — Accounting Project 2

## 📌 Project Overview

Project simulasi pengelolaan akuntansi dan keuangan menggunakan **Accurate 5 Standard Desktop**.

Project ini mencakup setup perusahaan, pengelolaan master data, transaksi pembelian dan penjualan, pengelolaan persediaan menggunakan metode **Average Cost**, pencatatan piutang, pembayaran supplier, beban operasional, hingga penyusunan laporan keuangan.
